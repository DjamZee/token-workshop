# Token Workshop — Atelier de jetons

Turn character portraits into framed round tokens for virtual tabletops (Foundry VTT, Roll20, Owlbear Rodeo…). Windows 10/11 64-bit, nothing to install: unzip and run.

**Download:** see [Releases](https://github.com/DjamZee/token-workshop/releases/latest).

- Drag the circle onto the face (auto-detected), pick one of the **208 bundled frames** (cyberpunk, corporate, magic, Matrix, gangs, military, fantasy-ready…), tweak its **hue / saturation / brightness**, and make all tokens in one click.
- Add your own frames (PNG or WebP with a transparent centre) with **Ajouter des cadres…**; name them `TF - <Theme> (<Variant>) <N>.png` and rules in `fabrique\cadres.csv` hand them out automatically (fantasy rules — elf, dwarf, orc, knight, cleric, rogue, undead — are ready and wake up as soon as a matching frame exists).
- Save a recoloured frame as a new frame of its family.

The interface is in French; a short English guide is at the end of [LISEZ-MOI.md](LISEZ-MOI.md).
